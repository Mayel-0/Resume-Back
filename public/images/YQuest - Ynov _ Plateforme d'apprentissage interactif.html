Query parameters

Tout paramètre de fonction qui n'est pas dans le chemin est un query parameter : il arrive après le ? dans l'URL, par exemple /essaim?limite=5.

@app.get("/essaim")
def essaim(limite: int = 10):
    return {"limite": limite}

Règles à retenir :

  • Valeur par défaut fournie : le paramètre est optionnel (limite: int = 10).
  • Pas de valeur par défaut : le paramètre est obligatoire. S'il manque, FastAPI renvoie 422.
  • Les types sont convertis : ?limite=5 devient un int.

Ce qu'on attend

  1. Route GET /essaim avec un query limite (int, défaut 10) qui renvoie {"limite": limite}
  2. Route GET /recherche avec un query nom (str, obligatoire) qui renvoie {"resultat": nom}

💡 Un query obligatoire manquant doit déclencher une 422 tout seul.
